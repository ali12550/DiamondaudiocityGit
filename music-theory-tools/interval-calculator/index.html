Quick Summary

This Interval Calculator helps you quickly determine the interval between any two notes in semitones, useful for music theory, composition, and songwriting.

How it works

The calculator counts the number of semitones between the selected notes and determines the interval type.

Semitones calculation:
C → C# = 1, C → D = 2, C → D# = 3, etc.
Interval type based on semitones:
1 = minor 2nd, 2 = major 2nd, 3 = minor 3rd, 4 = major 3rd, 5 = perfect 4th, 7 = perfect 5th, 12 = octave
